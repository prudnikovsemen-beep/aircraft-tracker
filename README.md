# Aircraft Tracker

Учебный проект трекера самолётов на Python. Реализует получение данных о воздушных судах через OpenSky Network, геокодирование стран через Nominatim и хранение данных в JSON. Проект разработан в стиле TDD (Test-Driven Development) с полным покрытием тестами и строгой типизацией.

## Стек технологий

- **Язык:** Python 3.12
- **Управление зависимостями:** Poetry
- **Тестирование:** pytest + pytest-cov
- **Статический анализ:** flake8, mypy
- **HTTP-запросы:** requests
- **Мокирование:** responses
- **Архитектура:** Абстрактные базовые классы (`BaseAPI`, `BaseStorage`)

### Особенности реализации
```bash
Абстракция API: Классы NominatimAPI и OpenSkyAPI наследуются от BaseAPI, что позволяет легко заменять или расширять 
источники данных. Реализована обязательная передача заголовка User-Agent для соблюдения правил использования API.

Гибкая типизация ответов: Метод BaseAPI.get возвращает list | dict, что корректно обрабатывает разные форматы ответов 
от внешних сервисов (список самолётов от OpenSky и список результатов от Nominatim).

Валидация данных: Класс Aircraft инкапсулирует логику валидации (запрет на отрицательную высоту и скорость). 
Некорректные данные от API фильтруются на уровне оркестрации с логированием предупреждений.

Локальное хранилище: JSONStorage автоматически создает директорию и файл, обрабатывает ошибки чтения/записи и 
предоставляет методы CRUD для данных о самолётах.

Тестирование моками: Тесты для API-клиентов используют библиотеку responses для изоляции от внешних сетей, 
гарантируя стабильность CI/CD и скорость прогона тестов.
